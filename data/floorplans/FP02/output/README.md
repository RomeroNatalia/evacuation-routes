# Generated outputs for FP02

Run `python scripts/run_preprocessing_pipeline.py --floorplan FP02` to rebuild deterministic routing, congestion, matrix, and visualization files. QUBO solver folders appear here after the corresponding solver is run.

The route catalog, edge index, binary incidence matrix, and occupancy-weighted incidence matrix are included and are ready for Neal, Hybrid, or QPU scripts. No cloud solver jobs were submitted during integration.
